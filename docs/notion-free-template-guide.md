# 나만의 온라인 건물주 OS 만들기

사업이 자라는 모습을 3D 도시로 보고, 내 매출 자료를 관리하는 무료 로컬 템플릿 사용 설명서입니다.

> 배포자 안내: 이 원고는 Notion에 복사할 수 있는 Markdown입니다. 아직 Notion에 게시하지 않았습니다. 코드에는 MIT License(Copyright (c) 2026 kimdokrae)가 적용됩니다. 권리 미확인 레거시 이미지·마스크는 ZIP에서 제외했습니다. Windows 실기와 실제 공개 승인은 별도입니다. 실제 검증 결과는 ZIP에 함께 있는 `docs/free-template-final-release-audit.md`를 확인하세요.

## 1. 온라인 건물주 OS란?

내가 운영하는 사업을 작은 공중섬의 건물로 표현합니다. 웹사이트는 운영 건물, 쇼핑몰은 상점, 개발 프로젝트는 공방처럼 관리할 수 있습니다. 대표는 중앙본부에서 경영 지표와 알림을 보고 직원 캐릭터를 선택해 자료를 확인합니다.

이 프로그램은 내 컴퓨터에서 켜는 웹앱입니다. 인터넷에 자동으로 내 회사를 공개하지 않습니다. 직원이 움직여도 실제 AI 모델이 업무를 실행한다는 뜻은 아닙니다.

## 2. 무료 템플릿에서 할 수 있는 일과 없는 일

**가능:** 3D 도시 탐험·회전·확대·전체 화면, 5종 건물·12개 부지 관리, 건설 단계 변경, 내부 오피스·직원 선택, 회사·건물·부서·직원·메뉴 이름 변경, 데모 체험, 수동·CSV 재무 입력, KPI·차트·직원 보고, 알림 읽음, 자동화 후보 업무 기록·분석·계획 검토, 개인 백업·복원.

**현재 불가:** 실제 AI 직원 실행, 자동 콘텐츠 발행·결제·배송 처리, 외부 금융/사이트 API 자동 수집, n8n·DB 자동 연결, 팀 공동 사용, 로그인·클라우드 동기화·자동 백업. 별도 개발·인증·보안 구성이 필요합니다. 알림 읽음은 실제 결제나 승인 처리와 다릅니다.

## 3. 설치 전 준비물

- 개인용 Mac 또는 Windows PC, 저장 공간과 설치 중 인터넷.
- **Node.js 24.x와 함께 설치되는 npm**. 다른 주요 버전 대신 24를 선택하세요.
- WebGL2를 지원하는 브라우저. 3D 실행이 안 되면 브라우저와 그래픽 가속 설정을 확인합니다.
- 무료 템플릿 ZIP. 다운로드 주소는 실제 공개 승인 후 배포자가 제공합니다. 현재 원고에 가짜 다운로드 링크를 넣지 않았습니다.

Docker·n8n·Neon·ChatGPT 유료 계정·API 키는 기본 실행에 필요하지 않습니다. AI로 코드를 수정할 때 사용하는 서비스의 계정/이용 조건은 별개입니다.

[Node.js 공식 다운로드](https://nodejs.org/en/download)에서 24 버전과 본인 OS를 선택하세요. Mac/Windows 환경을 구분하는 공식 설치 프로그램을 사용합니다.

## 4. Mac 설치 방법

1. Node.js 24용 Mac 설치 프로그램을 설치합니다.
2. 설치를 마친 뒤 **터미널을 새로** 엽니다. 이미 켜져 있던 터미널은 새 경로를 못 찾을 수 있습니다.
3. 다음 명령을 한 줄씩 입력합니다.

```sh
node --version
npm --version
```

정상 결과: 첫 줄은 `v24.`로 시작하고, 두 번째 명령은 npm 버전 숫자를 표시합니다. 앱에서 사용하는 정확한 Node 범위는 package.json의 `>=24 <25`입니다.

`command not found`라면 Node 설치를 완료했는지, 새 터미널인지 확인하세요. 시스템 폴더의 권한을 변경하거나 관리자 명령으로 우회하지 마세요. Mac Apple Silicon 개발 환경에서의 실행 확인과 ZIP 새 설치 결과는 작업 보고서에 기록합니다. 모든 Mac 버전에서 검증한 것은 아닙니다.

## 5. Windows 설치 방법

**Windows는 실행을 지원하도록 구성했지만 실제 Windows PC에서의 설치·3D·도우미 실행은 미검증입니다.** Mac에서 실행된 결과를 Windows 검증으로 표시하지 않습니다.

1. Node.js 24용 Windows 설치 프로그램을 설치합니다.
2. PowerShell을 새로 엽니다.
3. 다음을 실행합니다.

```powershell
node --version
npm.cmd --version
```

정상 결과는 `v24.`와 npm 버전입니다. PowerShell이 `npm.ps1` 실행 정책 오류를 보이면 `npm.cmd`를 사용하세요. 보안 정책을 통째로 해제할 필요가 없습니다.

화면/명령이 다르거나 설치가 실패하면 실제 Windows 버전, Node 버전, 비밀정보를 지운 오류를 배포자에게 전달하세요. 조직에서 관리하는 PC의 보안 정책은 관리자에게 문의합니다.

## 6. ZIP 다운로드·압축 해제

1. 배포자가 전달한 `online-landlord-os-free-template-v1-final-candidate.zip`을 받습니다. 이전 검토 파일은 `online-landlord-os-free-template-v1-review.zip`이므로 구분하세요. 후보는 독립 설치 검수용이며, REVIEW-STATUS.json의 `publicReleaseApproved: false`는 아직 게시·공개하지 않았다는 뜻입니다. 라이선스 미승인을 뜻하지는 않습니다.
2. Mac에서는 Finder에서 ZIP을 더블클릭합니다. Windows에서는 파일 탐색기에서 ZIP을 오른쪽 클릭 → **모두 압축 풀기** → 압축을 푼 폴더 열기를 선택합니다(Windows 화면 경로는 정적 안내, 실기 미검증). ZIP 미리보기 안에서 바로 실행하지 마세요.
3. 안쪽 `online-landlord-os` 폴더를 엽니다. 그 안에 `package.json`, `README.md`, `start-local.command`, `start-local.cmd`가 있어야 합니다.
4. 폴더 전체를 나중에도 찾을 수 있는 개인 위치에 보관합니다. 수익 백업과 실제 CSV는 별도 비공개 위치에 둡니다.

Node 의존성인 node_modules와 이전 사용자의 개인 자료는 ZIP에 포함하지 않습니다. 최초 실행 때 필요한 패키지를 다운로드하는 것이 정상입니다.

## 7. 처음 실행하는 방법

### Mac: 터미널

터미널에서 `cd `를 입력한 뒤 압축 푼 **package.json이 있는 폴더**를 창으로 끌어놓고 Enter를 누릅니다. 임의의 사용자명·다운로드 경로를 이 설명서에서 가정하지 않습니다.

이 폴더에서 다음을 실행합니다.

```sh
npm run doctor
npm ci
npm run dev:local
```

### Windows: PowerShell

압축 푼 폴더에서 터미널을 열거나 PowerShell에서 `cd ` 뒤에 실제 폴더 경로를 붙여넣습니다. 경로에 공백이 있으면 따옴표로 감쌉니다. 이어서 실행합니다.

```powershell
npm.cmd run doctor
npm.cmd ci
npm.cmd run dev:local
```

정상 결과: 준비 완료 안내와 Next.js 서버 시작 메시지가 표시됩니다. 터미널을 켜 둔 상태에서 브라우저로 **http://127.0.0.1:3003** 을 여세요. 첫 컴파일은 조금 기다려야 할 수 있습니다.

### 간편 도우미

Mac은 `start-local.command`, Windows는 `start-local.cmd`를 실행할 수 있습니다. Node 24를 먼저 설치해야 합니다. 처음에는 npm ci를 실행하고 이후에는 서버를 시작합니다. 도우미가 운영체제 보안 설정에 막히면 위 터미널 방식을 사용하세요. OS별 자동 실행·권한 팝업까지 모두 실기 검증된 것은 아닙니다.

**항상 같은 주소를 사용하세요.** 3003 대신 3000, localhost 대신 127.0.0.1처럼 주소를 바꾸면 다른 브라우저 저장소로 열릴 수 있습니다. 이때 기존 자료가 삭제된 것은 아닐 수 있습니다.

## 8. 실행 종료 및 다시 시작

- 종료: 서버가 실행 중인 터미널에서 Mac은 Control+C, Windows는 Ctrl+C. Windows가 종료 확인을 물으면 확인합니다.
- 다시 시작: 같은 프로젝트 폴더에서 Mac은 `npm run dev:local`, Windows는 `npm.cmd run dev:local`.
- 브라우저 창만 닫아도 서버는 켜져 있을 수 있습니다. 컴퓨터를 껐다 켜면 다시 서버를 실행해야 합니다.
- 매번 npm ci를 실행할 필요는 없습니다. 코드 버전의 의존성이 바뀐 경우에만 설치 안내를 확인하세요.
- 서버를 종료해도 같은 브라우저에 저장된 자료는 유지됩니다. 브라우저 데이터 삭제·시크릿 모드·다른 프로필은 별개입니다.

개발자가 프로덕션 실행을 확인하려면 개발 서버를 먼저 종료하고 `npm run build:local` 다음 `npm run start:local`을 실행합니다. 두 서버가 같은 3003 포트를 동시에 사용하게 하지 마세요.

## 9. 데모 회사 체험

1. 첫 화면에서 **데모 회사 체험하기**를 누릅니다.
2. 기존 3D 도시·가상 매출·차트와 직원 시뮬레이션이 표시됩니다. 샘플은 2026-09-21~10-20의 고정 30일 원장입니다.
3. 최근 7일·30일 버튼으로 같은 원장에서 계산한 지표를 봅니다. 30일 총매출은 **₩15,457,000**, 광고 추정수익은 **₩366,150**입니다. 실제 회사의 수익이 아닙니다.
4. 도시는 KPI 카드 아래에 있습니다. 모바일에서는 아래로 스크롤하세요. 건물을 클릭하면 운영 KPI와 내부 입장 버튼이 표시됩니다. 전체 화면에서 ESC로 나올 수 있습니다.
5. 직원 시뮬레이션을 재생·일시정지할 수 있습니다. 초기화는 가상 흐름에 대한 조작이며 실제 외부 업무를 취소하지 않습니다.

기존 회사 설정이 있으면 첫 실행 선택을 강제로 다시 띄우지 않습니다. 사이드바 아래 **처음 사용 안내**로 수동 진입하거나 설정의 데이터 모드에서 체험 ON을 선택하세요.

## 10. 내 회사 만들기

1. 첫 화면에서 **내 회사 만들기**.
2. **회사 이름·도시 이름**을 입력하고 **저장하고 다음**.
3. 기존 사업 건물에 이름을 붙입니다. 예: paper-garden 건물을 내 웹사이트 사업으로 사용합니다. 내부 ID는 바뀌지 않습니다.
4. 직원의 이름·직책을 정하고 다음으로 이동합니다. 실제 AI 실행이 연결되는 것은 아닙니다.
5. **수익 자료 연결하기**를 누르면 데이터 연결센터로 이동합니다. 이 과정에서 없는 사업 ID만 기존 건물과 연결해 둡니다. 기존 매핑은 덮어쓰지 않습니다.
6. 자료 저장 후 **내 회사 만들기 이어가기**로 돌아와 **내 회사로 시작하기**를 누릅니다.
7. 준비된 자료가 없으면 **자료는 나중에 · 내 회사 시작**으로 시작할 수 있습니다. 이때 수익은 미연결이고 데모 돈을 대신 표시하지 않습니다.

중간에 새로고침해도 저장한 단계에서 이어집니다. 입력만 하고 다음을 누르지 않은 값은 저장되지 않습니다. **안내 처음부터 · 자료 유지**는 안내 진행만 되돌리며 기존 재무·업무 자료를 초기화하지 않습니다.

## 11. 건물·부서·직원 이름 변경

설정의 카테고리 탭을 사용합니다.

- **회사**: 회사명·대표·도시명·테마·시작 화면.
- **도시·건물**: 수정할 건물 선택 → 건물 표시 이름·설명·연결 자산 변경.
- **부서**: 부서명·색상·업무 설명 변경.
- **직원**: 직원 선택 → 이름·직책·부서·색상·표시 여부.
- **메뉴 / 페이지 / 경영 KPI**: 표시 이름·순서·숨김·안내 문구 변경.

입력은 미리보기에 반영됩니다. **설정 저장**을 눌러야 새로고침 후에도 유지됩니다. 이름 변경은 내부 ID를 변경하지 않습니다. 도시에서 새 건물을 만들려면 빈 부지를 선택하거나 건물 등록 버튼을 사용합니다. 기본 지원 부지는 12개입니다.

## 12. 샘플 CSV 다운로드

1. 설정 → **데이터 연결**.
2. **연결 안내·CSV 양식**.
3. **샘플 CSV 보기**로 첫 10행을 미리 봅니다.
4. **샘플 CSV 다운로드** 또는 **빈 CSV 양식 다운로드**.

샘플 파일은 실제 체험 원장에서 생성한 720행입니다. 누락된 비용은 0으로 만들지 않고 행을 생략합니다. 원래 7/30일 매출·환불·추정수익·지급액과 동일한 재무 합계를 만듭니다. 직원 업무·주문·방문자 기록은 이 재무 CSV에 포함하지 않습니다.

프로젝트 파일에도 `public/templates/skycity-sample-finance.csv`, `public/templates/my-finance-template.csv`가 있습니다. 샘플을 그대로 올리면 여전히 가상 숫자입니다. 개인 자료가 된 것으로 착각하지 마세요.

처음에는 `skycity-sample-finance.csv`를 복사해 `my-finance.csv`로 이름을 바꾼 뒤 수정하세요. 스프레드시트 앱에서 헤더는 그대로 두고 날짜·사업 ID·지표·금액·통화를 입력한 후 **CSV UTF-8**로 저장합니다. `my-finance-template.csv`는 헤더만 있는 빈 파일이므로 예시를 보고 데이터 행을 추가해야 합니다. 파일 이름만 `.csv`로 바꾼 Excel 통합문서(.xlsx)는 CSV가 아닙니다.

## 13. 내 수익 CSV 작성 및 업로드

### 컬럼과 예시

| 컬럼 | 뜻 | 예시 |
|---|---|---|
| date | 그 자료의 기준 날짜 | 2026-10-20 |
| businessId | 등록된 사업 고유 ID, 표시 이름이 아님 | paper-garden |
| metric | 지표 코드 | grossSales |
| amount | 그 일자의 합계, 쉼표·음수 없이 | 120000 |
| currency | 통화 | KRW |

```csv
date,businessId,metric,amount,currency
2026-10-20,paper-garden,grossSales,120000,KRW
2026-10-20,paper-garden,refunds,0,KRW
2026-10-20,paper-garden,adEstimate,3000,KRW
2026-10-20,paper-garden,cost,20000,KRW
2026-10-20,paper-garden,paidOut,50000,KRW
```

이 예시는 모두 가상입니다. 이 다섯 행의 순매출은 120000원, 순이익은 103000원입니다. 지급액 50000원은 별도 정산이므로 수익에 다시 더하지 않습니다.

지표 코드: grossSales 총매출, refunds 환불·취소, adEstimate 광고 추정수익, cost 운영비, paidOut 실제 지급액. **순매출·순이익은 계산값**이므로 이 이름을 metric에 입력하지 않습니다.

- 모르는 값은 해당 행을 생략합니다. 실제 해당 없음은 0입니다. 빈 금액은 유효하지 않습니다.
- 일자·사업·지표·통화당 **합계 한 행**입니다. 주문 하나씩 같은 날짜의 매출 행을 여러 개 넣지 말고 합계로 정리합니다.
- KRW/JPY는 정수, USD/EUR는 소수 둘째 자리까지. 서로 다른 통화는 자동 합산·환산하지 않습니다.
- UTF-8 CSV로 저장하세요. 최대 1MB·5,000행·50열, 전체 저장 행 제한도 있으므로 큰 원장은 나누거나 추후 서버 저장소를 개발해야 합니다.

### 클릭 순서

1. **사업·건물 연결**에서 사업을 등록하고 담당 건물을 고릅니다. 화면에 나온 사업 ID를 CSV에 사용하세요. 온보딩에서 만든 매핑이 있으면 다시 등록하지 않습니다.
2. **CSV 가져오기** → CSV 파일 선택.
3. 날짜·사업 ID·지표·금액·통화 열을 선택합니다. 다른 한글 헤더도 화면에서 매핑할 수 있습니다.
4. **검증 미리보기**. 이름·날짜·금액·중복 오류를 수정합니다. 이 단계에서는 아직 저장하지 않습니다.
5. **가져오기 확정**.
6. 체험 ON이면 그대로 샘플을 보여 줍니다. **체험 모드 OFF · 내 데이터**를 선택해야 내 입력을 조회합니다.
7. 도시·금고·담당 건물·직원 보고의 금액이 함께 바뀌는지 확인합니다.

미리보기에서 **가져오기 취소**를 누르면 기존 저장 자료는 바뀌지 않습니다. 파일이 잘못됐다고 브라우저 전체 자료를 지우지 마세요.

## 14. 매출·수익 그래프 보는 방법

30일 원장은 2026-09-21~10-20입니다. **선택 기간 매출 ₩15,457,000**과 **이번 달 누적 매출 ₩10,498,000**은 기간이 달라 같은 값이 아닙니다. 광고도 30일 합계 ₩366,150, 10월 누적 ₩272,300으로 구분합니다. 모두 고정 가상 예제입니다.

메인 도시의 KPI는 대표 요약, **금고**는 재무 분석 화면입니다. 7일·30일 기간을 선택하면 같은 원천의 카드와 차트가 바뀝니다. 개인 자료에서는 기록된 최신 기준일을 사용하며 없는 날짜를 임의로 만들지 않습니다.

- 총매출: 환불 전 기록 합계.
- 환불·취소: 매출에서 빼는 금액.
- 순매출: 총매출 − 환불.
- 광고 추정수익: 광고에 대한 추정치. 매출이나 확정 지급액과 다릅니다.
- 운영비: 직접 기록된 비용. 빠진 비용을 임의로 0으로 보지 않습니다.
- 순이익: 일자·사업별 매출·환불·광고·비용이 모두 있어야 계산. 부족하면 **산정 불가**.
- 실제 지급액: 정산 받은 금액. 위 수익에 다시 더하지 않습니다.

건물 KPI는 매핑한 사업만, 중앙본부는 전체 자료를 요약합니다. 직원 보고도 같은 집계를 사용합니다. 개인 모드의 직원은 **업무 미연결**이며 자료 확인 카드가 실제 AI 분석 보고서는 아닙니다.

## 15. 매일·매주 데이터 갱신 방법

**수동 입력:** 데이터 연결 → 직접 입력 → 새 날짜·사업·지표·금액 → 재무 자료 저장. 틀린 값은 자료·연결 관리에서 자료 수정.

**CSV:** 원본 파일을 최신 자료로 고친 뒤 다시 업로드합니다. 전체 기간을 다시 넣을 때는 **교체할 CSV 자료**에서 이전 가져오기를 고르세요. 겹치지 않는 새 날짜만 추가할 수도 있습니다. 중복은 자동으로 더하지 않고 오류로 막습니다.

**자동 동기화:** 현재 미구현, **추가 개발 필요**. CSV를 한 번 올리거나 파일을 컴퓨터에 저장했다고 앱이 자동으로 읽지 않습니다. 서버를 다시 켜도 외부 플랫폼에서 최신 매출을 가져오지 않습니다.

추천 습관: 매일 또는 매주 원본 확인 → 새 수치 입력/CSV 교체 → 금고의 기준일·갱신 시각·합계 확인 → 개인 백업 다운로드. 자동 갱신 알람이나 주기 실행기는 이 템플릿에 없습니다.

## 16. n8n 등으로 자동 업데이트하려면 필요한 것

현재는 실제 연결을 하지 않습니다. 향후 개발할 구조 예시입니다.

```text
사용자 자신의 데이터 원천
  → n8n의 주기 조회(최소 권한 자격증명)
  → 인증된 서버 수집 API / 작업 계층
  → 사용자·Workspace로 격리한 서버 저장소
  → 권한을 확인하는 서버 조회 API와 외부 Provider
  → 기존 공통 재무 형식·집계
  → 대시보드·건물·직원 자료 카드
```

외부 서버가 브라우저 localStorage에 직접 쓰는 구조가 아닙니다. 브라우저는 인증된 API를 통해 서버 자료를 읽어야 합니다. 수동·CSV·외부 Provider가 같은 재무 의미와 중복 키를 사용하고, 이벤트 ID로 알림 중복을 막아야 합니다.

필요한 개발: 사용자 인증, Workspace 권한, 서버 전용 비밀값, 읽기 전용 조회, 원천 ID/날짜/통화 계약, 중복·재시도·오류·마지막 성공 시각, 동의와 비용 관리. 기존 n8n이 있다면 실행·수정 전에 별도 조사를 하고 중복 워크플로를 만들지 않습니다. 이 템플릿의 공개 모드 API 차단을 단순히 지워 연결하지 마세요.

## 17. 데이터 저장 위치·백업·초기화

현재는 이 브라우저의 localStorage입니다. 소스 폴더나 자동 클라우드 DB에 저장하지 않습니다. 다른 주소·포트·브라우저·시크릿 모드에서는 같은 자료가 보이지 않을 수 있습니다. 개인 템플릿 키는 `online-landlord-os:local-template:*` 범위이며 공개 체험·이전 모드와 분리됩니다.

### 전체 개인 백업

1. 설정 → 데이터 연결 → **개인 백업**.
2. **개인 백업 다운로드**.
3. `my-company.local-backup.json`을 소스 폴더 밖 비공개 위치에 보관합니다. 회사 로고·프로필·건물 단계·재무·발굴실 업무·KPI 표시·시작 안내가 포함됩니다.
4. 복원 전 현재 백업을 받고, 다른 앱 탭을 닫습니다.
5. **개인 백업 복원**에서 파일을 선택하고 자료 교체 확인창에 동의합니다.
6. 검증 후 새로고침됩니다. 잘못된 형식은 쓰기 전에 거부합니다. 저장 용량이 막히면 복원/원복이 실패할 수 있으므로 원본 백업을 꼭 보관하세요.

기존 **설정 JSON 내보내기**는 표시 설정만, 발굴실 **업무 원본 백업**은 해당 업무만 담습니다. 전체 보관과 다릅니다. 전체 개인 백업은 공개용 템플릿이 아니며 인증키를 보관하는 용도로 사용하면 안 됩니다.

### 초기화는 목적에 맞게

- 체험 수익 보기: 데이터 모드 ON. 개인 자료 삭제가 아닙니다.
- 가져온 파일만 빼기: 자료·연결 관리 → 연결 해제(보관) 또는 자료 삭제(확인 후 제거).
- 표시 설정만 복원: 설정 → 저장·이동 → 모든 설정 기본값 복원. 먼저 백업하세요.
- 발굴실만 초기화: 해당 화면의 별도 확인 버튼. 전체 회사 자료와 구분합니다.

브라우저 사이트 데이터 삭제는 되돌릴 수 없을 수 있습니다. 처음 실행 안내만 다시 보려면 사이드바 **처음 사용 안내**를 사용하고 전체 저장소를 지우지 마세요.

## 18. 오류 해결 방법

| 문제 | 먼저 할 일 |
|---|---|
| node/npm을 찾을 수 없음 | Node.js 24 설치 후 터미널 새로 열기 |
| npm.ps1 실행 정책 오류 | PowerShell에서 npm.cmd 사용 |
| package.json 없음 / ENOENT | ZIP 안쪽 프로젝트 폴더인지 확인 |
| 패키지 다운로드 실패 | 인터넷·회사 프록시 확인 후 npm ci 재시도, 버전 임의 변경 금지 |
| 3003 포트 사용 중 | 전에 켠 서버/터미널을 찾아 종료하고 다시 시작. 알 수 없는 프로세스 강제 종료 금지 |
| 화면이 열리지 않음 | 서버 터미널 오류 확인, 정확한 127.0.0.1:3003 주소 확인 |
| 3D가 비어 있거나 WebGL 오류 | 지원 브라우저·그래픽 가속 확인, 다른 지원 브라우저에서 체험. 개인 자료는 브라우저 간 자동 이전되지 않음 |
| 내 수치 대신 샘플이 보임 | 데이터 모드 OFF와 저장/연결 상태 확인 |
| 자료가 사라진 것 같음 | 주소·포트·프로필·시크릿 여부부터 확인, 초기화 금지 |
| CSV 사업 ID 오류 | 사업 등록·건물 매핑 화면의 ID와 파일 값 비교 |
| CSV 중복 오류 | 같은 합계가 이미 저장됐는지 확인, 전체 파일 재업로드는 이전 CSV 교체 |
| 순이익 산정 불가 | 각 일자·사업의 매출·환불·광고·비용 누락 확인, 모르는 비용을 0으로 채우지 않기 |
| 저장 용량 초과 | 개인 백업과 원본 CSV 보관 후 자료 규모 점검. 브라우저 전체 초기화로 해결하지 않기 |
| Windows 도우미 오류 | 위 PowerShell 수동 명령으로 재현하고 Windows 미검증 범위로 보고 |

도움을 받을 때 Node 버전, OS, 사용 주소, 수행 단계, 개인정보를 가린 화면과 오류 일부를 전달하세요. `.env.local`, API 키, 개인 백업은 보내지 마세요.

## 19. ChatGPT로 기능 수정·확장하는 방법

먼저 개인 백업과 코드 폴더 복사본을 만듭니다. ChatGPT에 README·AGENTS.md와 변경에 필요한 소스만 제공합니다. 파일 첨부가 지원되지 않으면 작은 관련 파일의 코드를 나눠 붙여넣고 경로를 적습니다. 전체 컴퓨터나 개인 백업을 올리지 마세요.

첫 요청 예시:

```text
이 프로젝트의 README.md와 AGENTS.md를 먼저 읽어 주세요.
현재 기능과 저장 키, buildingId/assetId/employeeId를 유지하세요.
수익 원장은 가상 예제로만 확인하고, 개인 백업이나 환경 파일을 요구하지 마세요.
이번에는 건물 정보 카드의 글자 크기만 개선해 주세요.
변경 파일, 적용 순서, 테스트 명령, 되돌리는 방법을 알려 주세요.
새 패키지·외부 연결·라이선스 변경은 먼저 설명하고 승인받으세요.
```

ChatGPT가 제안한 명령을 이해하지 못하면 실행 전에 설명을 요청하세요. 코드 답변만으로 내 PC 파일이 수정된 것은 아닙니다. 적용한 파일과 실제 검사 결과를 확인합니다. 제품의 파일·작업 기능은 계정/환경에 따라 다릅니다. [공식 ChatGPT 파일 활용 안내](https://learn.chatgpt.com/docs/use-chatgpt)를 참고하세요.

## 20. Claude·Codex로 기능 수정·확장하는 방법

로컬 코딩 도구를 사용할 때 **압축 푼 프로젝트 폴더만** 작업 범위로 지정합니다. README와 AGENTS.md를 먼저 읽으라고 요청하고 수정 전 개인 백업을 받습니다. 이 템플릿은 AI 계정 연결을 자동으로 설정하지 않습니다.

Codex는 AGENTS.md로 프로젝트 작업 지침을 읽을 수 있습니다. 현재 AGENTS.md에는 저장 키·공개/로컬 권한·개인 자료 보호·검증 경계가 적혀 있습니다. [공식 AGENTS.md 안내](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Claude Code에서도 README와 AGENTS.md를 명시적으로 읽도록 요청하세요. 자체 프로젝트 지침을 추가할 때는 공식 도구 설명의 CLAUDE.md 방식을 참고할 수 있습니다. 이 템플릿이 두 도구를 설치하거나 같은 지침 자동 적용을 보장하지는 않습니다. [Claude Code 공식 개요](https://code.claude.com/docs/en/overview).

완료 후 다음을 실제 실행하도록 요청합니다.

```sh
npm test
npm run typecheck
npm run build:local
```

브라우저 동작을 바꿨다면 관련 Playwright 검사도 요청합니다. 실패 테스트 삭제나 skip으로 통과 처리하지 않도록 지시하세요. 더 구체적인 건물·직원·대시보드·외부 API 프롬프트는 별도 `docs/ai-customization-guide.md`에 있습니다.

## 21. 코드를 안전하게 AI에 전달하는 방법

전달 가능: 필요한 app/components/lib 소스, package.json/잠금 파일, README/AGENTS.md, 가상 CSV, 개인정보를 가린 화면.

전달 제외: `.env*` 실제 값, 인증 파일, 토큰·DB 주소·Webhook, 개인 백업, 실제 수익 CSV, 고객·직원 개인 정보, 실행 로그, 브라우저 프로필, .git 이력, node_modules, .next*, docs/references의 제3자 참고 소스.

이름과 계정 ID를 지울 때 실제 저장 ID를 코드에서 일괄 교체하지 마세요. 공유용 복사본에서만 가상 값으로 바꾸고 원본은 보존합니다. 검토 ZIP의 패턴 검사도 모든 비밀값 탐지를 보장하지 않습니다. 민감정보가 들어갔는지 직접 확인하세요.

안전한 요청: 한 번에 한 기능, 수정 범위·보존할 저장 키·성공 기준을 명시합니다. 외부 서버 배포, DB 쓰기, 공개 저장소 업로드는 별도 승인 없이 하지 말라고 적습니다.

## 22. 자주 묻는 질문

**실제 AI가 일하나요?** 아니요. 체험은 브라우저 시뮬레이션이고 개인 모드는 업무 미연결입니다.

**무료로 수익이 생기나요?** 아니요. 체험 돈은 가상이며 개인 수치는 본인이 입력합니다. 실제 수익을 만드는 외부 업무는 수행하지 않습니다.

**CSV를 올리면 매일 알아서 갱신되나요?** 아니요. 새 수동 입력 또는 CSV 재업로드가 필요합니다. 자동 수집은 추가 개발입니다.

**공개 웹 DEMO에 내 실제 자료를 올려도 되나요?** 공개 체험에는 가상 자료만 사용하세요. 개인 회사 기능은 로컬 설치에서 사용합니다.

**다시 체험 ON을 켜면 내 자료가 지워지나요?** 아니요. 조회 원천만 바뀌며 서로 합산하지 않습니다.

**회사 이름을 바꾸면 매핑이 끊기나요?** 표시 이름과 ID가 분리됩니다. 일반 설정 변경은 고유 ID를 바꾸지 않습니다.

**내 컴퓨터를 끄면요?** 서버는 다시 켜야 합니다. 같은 브라우저 주소의 저장 자료는 남지만 별도 백업을 권합니다.

**다른 PC에서도 보이나요?** 자동 공유되지 않습니다. 개인 백업을 비공개로 옮기고 로컬에서 검증·복원하세요.

**코드 폴더를 지우면 자료도 없어지나요?** 브라우저 저장과 별개지만 같은 주소로 다시 실행해야 접근할 수 있습니다. 폴더와 개인 백업을 둘 다 보관하세요.

**12개보다 많은 건물, 더 많은 직원도 가능한가요?** 현재 기본 범위는 12개 부지와 기존 직원입니다. 3D 배치·경로·설정·검증을 함께 확장해야 하며 이름 배열만 늘리는 변경은 피하세요.

**기존 브라우저 테스트에서 레거시 이미지 항목이 실패해요.** ZIP은 권리 미확인 배경·마스크를 제외합니다. 이전 이미지를 기대하는 기존 테스트는 보존돼 있으며 ZIP에서 전체 통과 대상으로 주장하지 않습니다. 새 배포 흐름은 `npm run test:template -- --workers=1`로 검사합니다. 테스트 삭제·skip 또는 미확인 파일 재포함으로 해결하지 마세요.

**코드를 수정·재배포해도 되나요?** 프로젝트 자체 코드는 MIT License입니다. Copyright (c) 2026 kimdokrae 및 LICENSE의 허가 고지를 유지하면 수정·확장·재배포·상업적 이용이 가능합니다. 무보증 조건을 포함한 원문과 제3자 고지도 확인하세요. 외부 이미지·라이브러리는 각자의 권리를 따르며 미확인 레거시 에셋은 ZIP에 없습니다. 이전 2D/world-v2 경로는 제외 안내를 표시합니다. 기본 3D 도시·오피스를 이용하세요.
